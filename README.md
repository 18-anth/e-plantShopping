# e-plantShopping

e-plantShopping is a React-based web application for browsing plants, learning about each item, and managing a shopping cart in a simple storefront experience.

## Project Overview

This repository contains the **e-plantShopping** project, built with Vite and React. The app includes:

- A product listing interface for plant items.
- A cart flow powered by Redux state management.
- Reusable components for product display, cart items, and informational sections.

## Tech Stack

- React
- Vite
- Redux Toolkit

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```
